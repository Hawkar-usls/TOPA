## 0. Purpose

U1-E showed that raw chosen-proof depth is presentation-sensitive and full semantic quotienting is coNP-hard in general B2 scope. This does not imply that derivational ranks are impossible.

The classical extended-resolution proof of the pigeonhole principle provides a positive control: a family-specific, polynomially generable recursive proof with an exact decreasing stage parameter.

This is the shape a useful JANUS rank should imitate.

---

## 1. External construction

Stephen Cook's extended-resolution proof of the pigeonhole principle recursively reduces a standard pigeonhole formula `PHP(n)` to `PHP(n-1)` using newly defined variables.

A modern explicit account is:

Isaac Grosof, Naifeng Zhang, Marijn J. H. Heule, **Towards the shortest DRAT proof of the Pigeonhole Principle**, PoS/2022, arXiv:2207.11284.

They state that Cook introduced variables

`x'_{ph} <-> x_{ph} OR (x_{nh} AND x_{pn})`

and used `O(n^3)` clauses in the recursive reduction from size `n` to `n-1`, for a total extended-resolution proof of `O(n^4)` clauses. The recursion terminates at the constant-size base instance.

The external source supplies the polynomial ER construction. It does not prove any universal Akinator theorem.

## 2. Frozen family-specific rank

For an exact canonical standard PHP state of stage parameter `m`, define

`mu_PHP(m) := m - 1`

with the terminal base case at `m=1`.

Then every Cook recursive reduction has

`mu_PHP(m-1) = mu_PHP(m) - 1`.

Thus the stage rank is:

- a nonnegative integer;
- bounded by the original family parameter;
- trivially polynomially computable from the canonical stage metadata;
- strictly decreasing under the known certified recursive step;
- zero at the frozen base case.

---

## 3. B2 compatibility

The Cook macro uses

`x' = a OR (b AND c)`.

Frozen B2 has only AND over signed literals, but De Morgan gives a constant-overhead realization:

1. `t <-> (b AND c)`;
2. `u <-> ((NOT a) AND (NOT t))`;
3. use signed literal `NOT u` as the value `a OR t`.

So each Cook extension macro has constant B2-definition overhead up to the surrounding proof simulation already established in the project.

This means the family-specific stage rank is compatible with the frozen B2 vocabulary; it is not an artefact of a different Boolean basis.

## 4. Deterministic construction

For a canonical labeled `PHP(m)`:

- the stage parameter `m` is explicit in the incidence/index structure;
- the next Cook variables are generated by deterministic index loops;
- the extension definitions are determined by the formula above;
- the stage proof is generated by a fixed polynomial schema;
- the next canonical goal is `PHP(m-1)`.

No semantic candidate ranking, SAT oracle, model counting, or exponential schema search is needed on this family.

The rank therefore meets the intended Akinator pattern:

`RECOGNIZE_STAGE -> GENERATE_CERTIFIED_MOVE -> DECREASE_RANK -> REPEAT`.

## 5. Complexity accounting

The external construction uses `O(m^3)` proof clauses/work per recursive reduction and `O(n^4)` total clauses across all stages from initial parameter `n`.

Since the standard PHP input itself has polynomial encoded length in `n`, this is polynomial in the input length as well.

The number of rank-decreasing stages is at most `n-1`.

Thus on this family:

**CHEAP_EXACT_CERTIFIED_DERIVATIONAL_RANK = ACHIEVED.**

This is only a family-specific theorem.

## 6. Why this matters

Earlier negative results could have suggested that all useful potentials secretly equal shortest-proof search. Cook's PHP construction disproves that overgeneralization.

Here the rank is not obtained by solving a generic shortest-proof problem. It comes from an independently recognizable recursive structure and a fixed proof generator.

Therefore the correct universal target is not necessarily “compute distance to the best proof.” It can be:

> detect a certified structural reduction stage whose proof is generated locally and whose stage rank decreases.

This is the closest rigorous form so far of the Mathematical Akinator intuition.

## 7. Universalization gap

The unresolved question is enormous but now precise.

For arbitrary CNF `F`, can we define a polynomial-size **certified stage descriptor** `D(F,S)` such that:

1. the descriptor is found deterministically in polynomial time;
2. it chooses/generated one legal B2 move or bounded proof block;
3. a polynomial certificate proves the move maps the current obligation to a lower-rank obligation;
4. the rank has polynomial range in original input length;
5. every nonterminal state admits such a stage;
6. the scheme never requires semantic oracle calls or exponential alternative-stage search?

Cook/PHP answers YES only for one structured family.
