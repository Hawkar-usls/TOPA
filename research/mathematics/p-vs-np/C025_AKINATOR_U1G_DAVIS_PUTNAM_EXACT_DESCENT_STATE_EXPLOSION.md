## 0. Why this matters

The previous front asked whether Cook/PHP-style certified stage descent can be generalized to arbitrary CNF. The classical Davis–Putnam variable-elimination procedure gives a striking answer:

- yes, there is a universal deterministic exact reduction stage;
- yes, an elementary rank decreases at every step;
- but the intermediate proof/state representation can grow exponentially.

This cleanly separates **descent** from **state-size control**.

---

## 1. Frozen Davis–Putnam elimination

Let `x` be a root variable of CNF `F`.

Partition the clauses into

- `R`: clauses not containing `x` or `~x`;
- `P_i = (x OR A_i)`;
- `N_j = (~x OR B_j)`.

Define

`DP_x(F) := R union { A_i OR B_j : i,j and the resolvent is non-tautological }`.

Duplicate clauses may be canonicalized away.

The construction is deterministic once the eliminated variable and canonical ordering are fixed.

---

## 2. Exact elimination theorem

For every assignment `beta` to all variables except `x`,

`beta |= DP_x(F)` iff there exists a value of `x` such that `(beta,x) |= F`.

Equivalently,

`DP_x(F) == exists x F`

as Boolean functions on the remaining variables.

### Proof

#### Forward from F

If `(beta,x)` satisfies `F`, then it satisfies every clause in `R`.

For every pair `(x OR A_i)`, `(~x OR B_j)`, their resolvent `(A_i OR B_j)` is a logical consequence by Resolution. Hence `beta` satisfies every retained resolvent.

So `beta |= DP_x(F)`.

#### Backward to a value of x

Assume `beta |= DP_x(F)`.

If all `A_i` are true under `beta`, choose `x=0`. Then every positive-x clause is satisfied by `A_i`, every negative-x clause is satisfied by `~x`, and `R` is already satisfied.

Otherwise some `A_i` is false. Since every resolvent `A_i OR B_j` is satisfied, all `B_j` must then be true. Choose `x=1`: all positive-x clauses are satisfied by `x`, all negative-x clauses by `B_j`, and `R` remains satisfied.

Thus some value of `x` extends `beta` to a model of `F`.

Therefore SAT is preserved exactly.

## 3. Universal exact descending rank

Let

`mu_DP(F) := number of variables not yet eliminated`.

Every Davis–Putnam stage removes exactly one variable and introduces no new root variable, so

`mu_DP(DP_x(F)) = mu_DP(F) - 1`.

After at most `n` stages no variables remain; the resulting zero-variable CNF is either trivially true or contains the empty clause, deciding SAT/UNSAT.

Hence Davis–Putnam supplies all of the following:

- universal stage availability for every nonterminal CNF with a remaining variable;
- exact SAT preservation;
- deterministic stage construction;
- a nonnegative integer rank of range at most `n`;
- strict rank descent at every stage;
- exact terminal correctness.

This is an important positive theorem:

**UNIVERSAL_EXACT_DESCENT_RANK_BY_ITSELF_IS_NOT_THE_MISSING_OBJECT.**

The missing obligation is polynomial total representation/work.

---

## 4. One-step clause-growth accounting

If `p` clauses contain positive `x` and `q` clauses contain negative `x`, elimination can generate up to

`p*q`

pairwise resolvents before tautology/duplicate pruning.

With `p+q <= M`, this is at most `M^2/4`, so one stage is polynomial in the **current explicit state size**.

But current-state polynomiality is exactly what must be proved relative to the original input `N`; it cannot be assumed recursively.

A simple finite family already realizes quadratic one-step growth:

`(x OR a_i)` for `i=1..m`

and

`(~x OR b_j)` for `j=1..m`,

with distinct variables `a_i,b_j`.

Eliminating `x` creates all `m^2` distinct clauses `(a_i OR b_j)`.

Thus even a single exact stage can square a clause bucket.

## 5. External unconditional Davis–Putnam lower bound

Zvi Galil, **On the complexity of regular resolution and the Davis-Putnam procedure**, Theoretical Computer Science 4 (1977), 23–46, DOI 10.1016/0304397577900548.

The paper constructs, for infinitely many `n`, contradictory conjunctive formulas `alpha_n` such that every regular proof tree requires `2^{c n}` distinct clauses for some constant `c>0`. Galil states that this implies a `2^{c n}` lower bound on the number of distinct clauses generated by the Davis–Putnam procedure on `alpha_n` **for any variable-elimination ordering**.

Therefore the naive universal Davis–Putnam Akinator cannot have polynomial total state/work on all CNFs.

This is an unconditional route closure for that exact procedure, not a P-vs-NP separation.

### Independent structural context

Rina Dechter's bucket-elimination framework later characterizes directional Resolution / variable elimination as having time and space exponential in the induced width (treewidth-like parameter) of the chosen ordering. This explains structurally where the intermediate-state growth arises, but Galil's theorem already gives the unconditional hard-family lower bound needed here.

## 6. The important lesson for JANUS

We now have a universal algorithm satisfying the strongest-looking Akinator property:

`EVERY STEP EXACTLY REDUCES THE NUMBER OF VARIABLES.`

Yet it is exponential because the proof/state representing the reduced problem grows too large.

Thus the central closure contract must simultaneously enforce

`STRICT DESCENT`

and

`POLY REPRESENTATION OF THE RESIDUAL OBLIGATION`.

Neither implies the other.

New law:

**PERFECT_DESCENT != POLY_STATE.**

This is the exact analogue of earlier laws

- short proof != cheap discovery;
- compact representation != cheap semantic intersection;
- polynomial work in current state != polynomial work in original input.

## 7. Why B2 extensions become the next compression question

Davis–Putnam materializes every required resolvent in CNF. B2/Extended Resolution can instead name intermediate Boolean structure with extension variables.

Therefore the natural repair is:

> do not materialize the full DP resolvent frontier; compress each exact eliminated residual into a polynomial-size proof-carrying B2 representation.

But this repair cannot be assumed.

The exact next gate is whether such compression can be **constructed deterministically in polynomial total work for every CNF and every stage** while preserving an exact descending elimination rank.

If yes, repeated elimination would give a polynomial SAT algorithm and hence `P=NP`.

If no, a lower bound on this compression mechanism would identify a stronger representation/proof bottleneck.
