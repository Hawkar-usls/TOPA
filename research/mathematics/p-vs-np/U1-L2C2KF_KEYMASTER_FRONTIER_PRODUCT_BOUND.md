# U1-L2C2KF — Keymaster Frontier Product Bound

## Status

Exact conditional theorem. This is **not** a proof that P=NP. It isolates the remaining obligations.

## Setting

For original source size `N`, let Keymaster retain states of the form `(s,c)` where:

- `s` is an exact canonical transition-state;
- `c=(c_1,...,c_d)` is the cumulative nonnegative integer cost vector;
- `d=9` is fixed by the JANUS ledger: state, proof, discovery, failed_search, build, projection, join, verify, witness;
- for each identical `s`, Keymaster removes a path only when another path to the same `s` has componentwise no larger cost and is strictly smaller in at least one coordinate (or is an exact equal-cost duplicate).

Assume:

1. At the considered stage there are at most `M(N)` distinct exact canonical transition-states.
2. Every surviving cumulative coordinate obeys `0 <= c_i <= B_i(N)`.

## Theorem

The exact non-dominated Keymaster frontier obeys

`|F_N| <= M(N) * min_j Product_{i != j} (B_i(N)+1)`.

Therefore, because `d=9` is fixed, if `M(N)` and every `B_i(N)` are polynomial in `N`, then `|F_N|` is polynomial in `N`.

## Proof

Fix one canonical state `s` and its set `A_s` of componentwise non-dominated cost vectors.

Choose any coordinate `j`. Project each vector in `A_s` onto the other `d-1` coordinates. This projection is injective. If two distinct vectors had identical coordinates except possibly coordinate `j`, the vector with smaller `j` coordinate would componentwise dominate the other, contradicting non-dominance. Thus

`|A_s| <= Product_{i != j} (B_i(N)+1)`.

This holds for every `j`, hence

`|A_s| <= min_j Product_{i != j} (B_i(N)+1)`.

Summing over at most `M(N)` canonical states gives the theorem.

- prove polynomial cumulative bounds `B_i(N)` for all nine charged coordinates.

The first item is directly coupled to `U1-L2C2C`: exact transition quotient discovery/creation.
