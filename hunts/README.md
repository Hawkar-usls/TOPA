# TOPA Native Hunts

This directory contains investigations that are born, preregistered, attacked and versioned **inside TOPA itself** rather than imported from earlier JANUS repositories.

Every native hunt must preserve at minimum:

```text
PREREGISTRATION.json
SOURCE_LEDGER.json
PASS-XXX-*.json
STATUS.json
README.md
```

A hunt may end as resolved, falsified, mixed, data-poor, replication-worthy or unresolved. `UNRESOLVED` is not a failure.
