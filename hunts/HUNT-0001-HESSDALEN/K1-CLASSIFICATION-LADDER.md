# HUNT-0001 K1 — Strict Classification Decision Registry

**Status:** strict-science interface; class names alone have zero evidentiary authority.

Every detected track begins as:

```text
UNCLASSIFIED
```

A class may be assigned only by a **frozen class rule** that existed before the holdout interval was scored and emits a reproducible receipt containing the measurements, reference data and tolerances used.

## Universal admission rule

For every assigned class, retain:

```text
track_id
source_frame_or_time_range
source_file_sha256
class_rule_id
class_rule_version
measured_features
reference_dataset_ids_and_versions
calibration_id
predeclared_tolerances
rule_result = PASS
code_commit_or_algorithm_version
```

If any required object is missing, the classification is not admitted.

```text
VISUAL_RESEMBLANCE != CLASSIFICATION
MODEL_LABEL_WITHOUT_VALIDATED_RULE != CLASSIFICATION
HUMAN_CONFIDENCE != CLASSIFICATION
NO_MATCH_FOUND != EXTRAORDINARY_CAUSE
```

## Frozen class namespaces

```text
ASTRONOMICAL
  STAR_OR_PLANET

CATALOGUED_TRAFFIC
  SATELLITE_OR_SPACECRAFT
  AIRCRAFT

ATMOSPHERIC_OR_BIOLOGICAL
  METEOR
  BIRD_OR_INSECT

OPTICAL_OR_ENCODING_ARTIFACT
  LENS_OR_INTERNAL_REFLECTION
  H264_OR_CODEC_ARTIFACT
  STACKING_ARTIFACT

UNCLASSIFIED
```

These are namespaces, not automatic decision rules. Each active class requires its own versioned gate before K1 holdout scoring.

## Minimum rule semantics by class

### STAR_OR_PLANET
Requires a timestamp/observer-location/camera-calibration projection against a frozen astronomical ephemeris/catalogue and a preregistered angular residual tolerance.

### SATELLITE_OR_SPACECRAFT
Requires a frozen orbit/reference dataset, timestamp basis, observer/camera calibration, propagated expected track and preregistered association tolerances. A visual streak is insufficient.

### AIRCRAFT
Requires a source-bound traffic/reference record when available or a separately validated kinematic classifier with declared false-match/false-negative evaluation. Apparent motion alone is insufficient.

### METEOR
Requires a frozen measurable temporal/morphological rule validated against labeled controls, or an independent source/catalogue match. Human visual impression is insufficient.

### BIRD_OR_INSECT
Requires a validated measurable classifier or independent near-field evidence. Blur/shape resemblance alone is insufficient.

### LENS_OR_INTERNAL_REFLECTION
Requires a reproducible optical/geometric test tied to camera configuration, such as repeatable source-image coupling or a validated artifact model.

### H264_OR_CODEC_ARTIFACT
Requires raw/decode evidence showing the feature is produced by encoding/decoding structure and is not present as the corresponding physical-image signal in an appropriate source representation.

### STACKING_ARTIFACT
Requires the feature to be absent from the corresponding raw source sequence and reproducibly generated by the frozen stacking pipeline.

## Residual state

If no frozen rule passes:

```text
UNCLASSIFIED
```

No `OTHER_CONVENTIONAL`, `LIKELY`, `PROBABLE`, `HARD_SURVIVOR` or similar narrative status is assigned.

`UNCLASSIFIED` means only:

> Under the frozen admitted rules and currently available source data, no class has been established.

It does **not** mean paranormal, extraterrestrial, novel physics, or even that all conventional explanations have been exhausted.

## Holdout firewall

Any detector, tolerance or association rule changed after inspection of a holdout event invalidates that event for confirmatory scoring under that rule. It may be moved to development data and a new untouched holdout must be used.

```text
POST_HOC_RULE_CHANGE => DEVELOPMENT_ONLY
HOLDOUT_REUSE_AFTER_TUNING => FORBIDDEN_AS_CONFIRMATORY_EVIDENCE
```
