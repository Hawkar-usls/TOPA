# Retrieval gate

Project Hessdalen publicly states that a full day of raw video is available for independent testing, but the current public web path resolves to a Google Drive folder whose directory listing is not exposed through this execution environment.

TOPA therefore records:

```text
PUBLIC_FULL_DAY_ASSERTED = YES
EXACT_RAW_DAY_ENUMERATED = NO
RAW_DAY_DOWNLOADED = NO
K1_REPLAY_EXECUTED = NO
STATE = ACQUISITION_OPEN
```

No curated clip is substituted. This preserves the preregistered blind-selection rule.
