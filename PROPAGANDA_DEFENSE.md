# TOPA Propaganda & Information Influence Defense

**Branch:** `topa-propaganda-defense`  
**Status:** `ACTIVE_DEFENSIVE_RESEARCH`  
**Coverage:** `NOT_EXHAUSTIVE`

This branch builds a provenance-bound JANUS/TOPA literature and methods surface for understanding propaganda, wartime/military information influence, contemporary FIMI/disinformation, and evidence-based countermeasures.

The objective is defensive:

```text
UNDERSTAND THE MECHANISM
→ PRESERVE PROVENANCE
→ SEPARATE CLAIM / BEHAVIOR / DISTRIBUTION / EFFECT
→ COLLAPSE DUPLICATE SOURCE ROOTS
→ BUILD COMPETING EXPLANATIONS
→ RUN REVERSE + SPIRAL
→ SELECT PROPORTIONATE EVIDENCE-BASED COUNTERMEASURE
→ MEASURE WHETHER IT WORKED
```

## Hard boundary

```text
DESCRIPTION_OF_INFLUENCE_TECHNIQUE != AUTHORIZATION_TO_USE_IT
MILITARY_DOCTRINE != TOPA_RECOMMENDATION
RED_TEAM_TTP != EXECUTION_PLAYBOOK
REACH != PERSUASION
PERSUASION != BEHAVIOR_CHANGE
MODEL_OUTPUT != ATTRIBUTION
COUNTER_PROPAGANDA_CAN_ITSELF_BECOME_PROPAGANDA
```

This branch does **not** provide real-world audience microtargeting, covert/deceptive influence campaign design, propaganda asset generation, moderation-evasion guidance, or military psychological-operation execution planning.

## Initial literature spine

The seed corpus includes historical work by Lasswell, Bernays and Ellul; modern academic surveys such as Jowett/O'Donnell; public NATO/UK/US doctrine as **descriptive context only**; RAND's *Firehose of Falsehood*; EEAS FIMI methodology and annual reports; DISARM; NATO StratCom COE counter-influence research; MSB counter-influence research; the *Debunking Handbook 2020*; misinformation/inoculation research; UNESCO media-literacy resources; and Ukrainian defensive practice from the Center for Countering Disinformation, OSCE-supported media-literacy guidance, StopFake, Detector Media and Media Center Ukraine.

Copyrighted works remain metadata/citation records unless reuse is clearly licensed. Community- or rights-sensitive material is not mirrored merely because it is online.

## JANUS analysis shape

```text
ARTIFACT
→ PROVENANCE
→ FACTUAL CLAIMS
→ OBSERVABLE TTPs
→ DISTRIBUTION / SOURCE-INDEPENDENCE GRAPH
→ AUDIENCE-EFFECT EVIDENCE
→ COMPETING HYPOTHESES
→ REVERSE NECESSITY PASS
→ DEFENSIVE RESPONSE
→ COUNTERMEASURE EFFECT
→ ORIGIN_PRIME
```

A claim can be false without being an organized propaganda operation. A propaganda artifact can contain true facts. Intent, coordination, attribution and causal audience effect are separate gates.
