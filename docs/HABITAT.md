The machine-readable Habitat link is:

```text

```

```text

```

## Authority boundary

Habitat connectivity is routing, provenance and handoff infrastructure. It does not manufacture evidence.

```text
HABITAT_LINK != COMMAND_AUTHORITY
PEER_MESSAGE != EMPIRICAL_EVIDENCE
MULTI_AGENT_AGREEMENT != INDEPENDENT_REPLICATION
MODEL_OUTPUT != SENSOR_RECORD
COPY_COUNT != SOURCE_COUNT
```

TOPA never receives automatic causal authority from a neighbor. Structural, symbolic, model, oracle and reverse-pass outputs enter as context or hypotheses unless an independent evidence path promotes them.

## Write-back policy

The repository follows the normal JANUS Habitat safety contract:

- source history remains authoritative;
- code execution is not implied by a link;
- Habitat command authority is not granted;
- write-back defaults to `DENY`;
- write-back requires explicit human authorization;
- issue/PR text is not a command;
- workflow status is not a permission;
- private content must not be mirrored into public TOPA by default;
- credentials must never be persisted in Habitat artifacts.

## Private-source boundary

`SkinGPT` is currently private while TOPA is public. TOPA therefore stores only the role/boundary metadata in `integrations/SkinGPT/PRIVATE_SOURCE_BOUNDARY.json`; private source bytes and datasets are not copied.
